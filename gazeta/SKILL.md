# Газета «Главные новости» (v2)

Выпуск собирается из короткого файла данных `issue.json`. Готовые скрипты верстают полосу и проверяют её, а живые иллюстрации берутся из библиотеки готовых сцен. Писать HTML и JavaScript не нужно.

Все пути ниже даны относительно папки этого скилла (`<скилл>`).

## 0. Язык, часовой пояс, страница

- **Язык выпуска** — язык пользователя, по умолчанию русский.
- **Часовой пояс.** Если пользователь его назвал, используй его. Если не назвал и человек на связи, спроси один раз. В запуске по расписанию бери Europe/Moscow для русскоязычного пользователя, иначе UTC.
- **Страница.** Если пользователь дал ссылку на свою газету (`https://claude.ai/artifact/...`), обновляй её. Если ссылки нет, создай новую страницу.

## 1. Время

Выполни `TZ=<пояс> date`. Окно выпуска — последние 24 часа. Подпись выпуска выбери по времени: «Утренний выпуск» до 12:00, иначе «Выпуск ЧЧ:ММ».

## 2. Новости — быстро

1. **Первый заход — одним сообщением.** Отправь сразу все поиски параллельно, в одном ответе: Мир, страна пользователя, Экономика и рынки, Технологии и наука, плюс одну-две готовые сводки дня (например, «что произошло за день» от Интерфакса или Известий, утренние обзоры агентств). Используй обычный режим поиска; расширенный нужен, только если результаты пустые или устаревшие.
2. **Второй заход — тоже одним сообщением.** Параллельно открой статьи: сводки дня и по одной статье на материал. Вторую статью открывай только для сверки ключевых цифр (жертвы, деньги, проценты, даты).
3. Отбери **6–8 материалов**, только по-настоящему новые за окно. Самый важный станет главным.

Не больше трёх раундов инструментов на сбор новостей.

## 3. Данные выпуска

Запиши `issue.json` по образцу `<скилл>/assets/example.json`.

**Поля:**

| Поле | Что в нём |
|---|---|
| `lang` | код языка выпуска: `ru`, `en` и т. д. Для `ru` и `en` служебные надписи готовы; для другого языка добавь `ui` с переводами ключей `masthead`, `edition`, `live`, `last`, `joke`, `sources`, `archive`, `back`, `more`, `months` (12 месяцев в родительном падеже) |
| `seed` | дата в формате ГГГГММДД |
| `slug` | дата и время выпуска: `ГГГГ-ММ-ДД-ЧЧММ`, например `2026-10-28-0845` — имя архивной копии |
| `archive` | пути уже опубликованных выпусков из шага 7.1 (`archive/….html`); на первом выпуске — `[]` |
| `date_line` | день недели и дата, например «Вторник, 27 октября 2026» |
| `edition` | подпись выпуска из шага 1 |
| `city` | город |
| `window` | окно, например «События с 08:45 26 октября по 08:45 27 октября (МСК)» |
| `brief` | 2–3 предложения о главном |
| `lead` | главный материал: `label`, `title`, `art`, `paras` (2 абзаца), `src` |
| `aside` | два следующих по важности материала, той же формы, `paras` — 1 абзац |
| `columns` | 2–3 колонки: `label` и `items`, в каждой 1–3 материала (`title`, `art`, `paras`, `src`) |
| `joke` | `lines` (2–4 строки) и `note` |
| `sources` | список `{title, url}` |

- Цифры в тексте помечай как `[[2515]]` — они получат табличное начертание.
- Пиши своими словами, без длинных цитат.
- Пустых колонок не оставляй.

**Иллюстрация** (`art`) — `{"scene": ИМЯ, "caption": "описание", "params": {...}}`. Сцену выбери по каталогу ниже. В параметры пиши только цифры из источников, подписи — коротко и заглавными. Материалы о гибели людей, атаках, катастрофах и терактах оставляй без `art`.

## 4. Каталог сцен

| Сцена | Когда | Параметры |
|---|---|---|
| `river` | река, граница, коридор, эвакуация, перемирие | `river`, `place` |
| `orbit` | переговоры, саммит, встреча сторон | `labels` — 2–6 сторон |
| `calls` | звонки, связи, контакты между столицами | `hub` `[имя,x,y]`, `nodes` `[[имя,x,y],…]`, `target` `[имя,x,y]` (необязательно); x, y — доли 0..1 |
| `pipes` | газ, энергия, поставки, всё сходится к центру | `center`, `sources` (3–12) |
| `flow` | торговля, логистика, санкции, трафик, узкое горло | `left`, `right`, `label` |
| `bars` | 2–6 сравниваемых показателей: выручка, бюджет, результаты | `bars` `[[подпись, число],…]`, `prefix`, `suffix`, `decimals`, `ticker` |
| `level` | цена или уровень изменились с A на B: нефть, вода, запасы | `title`, `from`, `to`, `min`, `max`, `step`, `prefix`, `fromLabel`, `toLabel` |
| `ticker` | биржи, индексы, курсы | `big`, `sub`, `rows` (две строки) |
| `range` | ставка, коридор, прогноз и дата решения | `value`, `title`, `start`, `end` |
| `vote` | парламент, выборы, голосование | `seats`, `yes`, `big`, `label` — только реальные числа. Пока итогов нет, `yes` — порог большинства, а `big` и `label` прямо говорят, что это порог, а не результат |
| `grid` | ИИ, чипы, дата-центры, вычисления | `label` |
| `waves` | наука, физика, математика, связь | `label` |
| `pulse` | заявление, решение, открытие, запуск продукта | `label`, `x`, `y` |
| `rocket` | космос, запуск, спутники | `label` |
| `sea` | море, археология под водой, океан | `label`, `objects` (1–8) |

Если ни одна сцена не подходит, бери `pulse`. Новые сцены не пиши, если тебя об этом не просили.

## 5. Анекдот дня

Короткий анекдот собственного сочинения, 2–4 строки, по лёгкой новости выпуска: рынки, технологии, наука, курьёзы.

- Не шути про войну, смерти и катастрофы.
- Не вкладывай слова в уста реальных людей.
- Не используй стереотипы о народах и группах.

В `note` напиши «Сочинено редакцией по мотивам новости о …».

## 6. Сборка и проверка

```bash
python3 <скилл>/scripts/build.py issue.json gazeta.html
node <скилл>/scripts/check.js gazeta.html
```

`check.js` проверяет ошибки, наличие всех иллюстраций, горизонтальную прокрутку и плавность анимации на ширине 1200 и 400 px.

- Если он напечатал «ПРОБЛЕМА», исправь `issue.json`, пересобери и проверь ещё раз. Только в этом случае сделай скриншот: передай третьим аргументом путь к png.
- Если Playwright нет, проверка пропускается. Это нормально.

## 7. Публикация

**Есть инструмент Artifact:**
1. *Ссылка на газету известна* — ещё до сборки (шаг 6) получи список архива: `Artifact`, `action: "list"`, `scope: "files"`, `url`. Пути вида `archive/….html` впиши в `issue.json` → `archive`. Затем прочитай страницу (`action: "read"`, `url`).
2. `build.py` сам кладёт копию выпуска в `archive/<slug>.html` рядом с `gazeta.html`.
3. Опубликуй: `file_path` = `gazeta.html`, `url`, `files` = `{"archive/<slug>.html": "<путь к archive/<slug>.html>"}`, `description` «Выпуск за <дата>». Параметр `icon` не передавай. Прошлые архивные файлы публиковать заново не нужно: они сохраняются сами. Внизу полосы появится раздел «Архив выпусков» со ссылками на прошлые номера, а на каждой архивной странице — ссылка на свежий выпуск.
4. *Ссылки нет, или публикация по ней не удалась:* опубликуй так же, но без `url` и с `icon: "news"`. Дай пользователю ссылку и посоветуй сохранить её.

**Инструмента Artifact нет:** скажи пользователю, где лежит `gazeta.html`, и предложи открыть его в браузере.

- После первого выпуска один раз предложи сделать его ежедневным: задача по расписанию с текстом вида «Сделай газету скиллом gazeta. Часовой пояс: Europe/Moscow. Обновляй страницу: <ссылка>». Создавай задачу только с согласия пользователя.
