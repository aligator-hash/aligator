# aligator

Скиллы для Claude.

## gazeta — «Главные новости»

Газетная полоса с главными новостями за последние 24 часа: живые анимированные иллюстрации и анекдот дня.

**Установка:** скачайте папку [`gazeta`](./gazeta) архивом `.zip` и загрузите её в Claude как скилл. Затем попросите: «главные новости» или «утренняя сводка».
